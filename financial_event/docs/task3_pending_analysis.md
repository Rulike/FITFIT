## 与候选发布时间检查的关系

候选发布时间检查只验证候选对两端的时间字段；时间切分按组件处理，只要组件中任一document缺少或无法解析时间，整个组件进入pending，因此两者不矛盾。

## 时间处理原则

- 保留原始时间字符串。
- 优先使用 `article_metadata_index.jsonl` 按 `article_id` 回填。
- 可解析时间统一输出为带 UTC 标记的 ISO 时间。
- 不可解析或缺失时间不补猜，进入 pending。
